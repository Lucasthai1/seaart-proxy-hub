Onde ficam as credenciais

Todas as credenciais reais (SeaArt, ComfyUI, MCP) ficam apenas no .env da API, nunca neste painel.

SEAART_MODE=sdk SEAART_EMAIL=... SEAART_PASSWORD=... COMFY_MODE=cloud COMFY_API_KEY=... MCP_BEARER_TOKEN=...

Gerar imagem

curl -X POST http://127.0.0.1:8788/v1/images/generate \ -H "Content-Type: application/json" \ -d '{"prompt":"anime girl, clean lineart","user_id":"u1"}'

Rodar workflow Comfy

curl -X POST http://127.0.0.1:8788/v1/comfy/run \ -H "Content-Type: application/json" \ -d '{"workflow_id":"poster-v1","input":{"prompt":"cinematic poster"}}'
